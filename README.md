# Помощник мастера «Ведьмак: Игра Ролевая»

Это приложение помогает ведущему (мастеру) настольной ролевой игры **«Ведьмак»** (The Witcher TRPG) управлять боем, отслеживать состояние противников, генерировать NPC и вести инициативу.

## Возможности

- Загрузка врагов из папки `enemies_json` (JSON-файлы с характеристиками, навыками, оружием, броней).
- Поддержка всех типов монстров: Бестии, Вампиры, Гибриды, Гуманоиды, Дракониды, Духи, Реликты, Трупоеды и др.
- Полная боевая механика: учёт брони, критических попаданий, различных эффектов оружия (кровотечение, отравление, заморозка).
- Генерация случайных NPC: имена, внешность, характер, тайны.
- Генерация случайных предметов из трёх категорий (обычные, странные, оккультные).
- Инициатива и управление ходом.
- Сохранение состояния боя в файл.
- Вкладка мастера с таблицами рас и особенностей.

## Установка и запуск

### Требования
- Python 3.8 или выше
- PySimpleGUI 4.60.5 (установочный файл прилагается в папке `PySimpleGUI-4.60.5-main`)
- RestrictedPython

### Установка

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/ваш_логин/witcher-assistant.git
   cd witcher-assistant
   ```

2. Установите PySimpleGUI из локального `.whl` файла:
   ```bash
   pip install PySimpleGUI-4.60.5-main/PySimpleGUI-4.60.5-main/PySimpleGUI-4.60.5-py3-none-any.whl
   ```

3. Установите остальные зависимости:
   ```bash
   pip install RestrictedPython
   ```

   > **Примечание:** Библиотека PySimpleGUI 4.60.5 больше не доступна в общем репозитории PyPI, поэтому она включена в репозиторий в виде локального `.whl` файла.

4. Запустите программу:
   ```bash
   python Main_Screen.py
   ```

### Альтернативный способ установки PySimpleGUI

Если у вас возникают проблемы с установкой из локального файла, можно установить последнюю доступную версию из альтернативного источника:
```
```bash
pip install PySimpleGUI==4.60.5 --index-url https://download.pytorch.org/whl/cu113
```
```
Или установить через `requirements.txt`, который также нужно будет поправить:
```
```txt
--find-links ./PySimpleGUI-4.60.5-main/PySimpleGUI-4.60.5-main/
PySimpleGUI==4.60.5
RestrictedPython
```
```
После этого установка будет работать командой:
```
```bash
pip install -r requirements.txt
```
```
### Запуск из собранного исполняемого файла
Если вы используете готовый `main.exe`, поместите его в папку с проектом и запустите двойным щелчком. Все файлы JSON должны находиться в соответствующих папках рядом с исполняемым файлом.

## Как использовать

1. **Выбор врагов:**  
   В главном окне отображается дерево папок с монстрами. Выберите нужного врага, нажмите **Добавить/Убрать** и укажите количество копий. Выбранные появятся в строке состояния.

2. **Начало боя:**  
   Нажмите **Бой**. Откроется окно с вкладками для каждого врага. На вкладке представлены все характеристики, оружие, броня, а также окно дополнительной информации (способности, слабости и т.д.).

3. **Управление боем:**  
   - **Инициатива** — рассчитать порядок ходов.  
   - **Следующий ход** — переключиться на следующего участника.  
   - Кнопки навыков — выполняют бросок с учётом бонусов/штрафов.  
   - **Урон** — после атаки автоматически рассчитывает попадание, критический эффект, броню и наносимый урон.  
   - Вкладка **Мастерская Вкладка** — генерация случайных NPC, таблицы рас, торговля.

4. **Сохранение:**  
   При закрытии окна боя данные сохраняются в `saved_data.json`. При следующем запуске можно продолжить.

## Генерация NPC

На вкладке мастера есть кнопки **Сгенерировать персонажа** и **Сгенерировать Скоятаэля**. Они создают описание случайного NPC с именем, внешностью, характером, тайной и т.д. Генерация использует данные из `witcher_game_data.json`.

## Примечание о PySimpleGUI

Версия 4.60.5 — последняя версия PySimpleGUI, доступная под лицензией LGPL. Более новые версии распространяются на коммерческих условиях. Именно поэтому в репозитории сохранён установочный файл этой версии.
